### One session, step by step (75 min)
1. **(5 min)** Skim last session's summary; redo 1 old challenge you got wrong.
2. **(30 min)** Read the new notebook section by section, **running every cell** and changing values.
3. **(10 min)** Do the Exam Corner: answer theory questions on paper, predict outputs before running.
4. **(25 min)** Attempt challenge problems. Time-box each to 10 minutes before peeking at hints.
5. **(5 min)** Write 3 lines: *what I learned / what confused me / one thing to redo tomorrow.*

## ✍️ Exam-day technique (theory + practical)
1. **Read the whole paper first**; start with the questions you're surest about.
2. **Programs:** write a 1-line idea → the code → a sample input/output. Use meaningful names and short comments.
3. **Differentiate/compare questions:** always use a **table** with at least 4 rows.
4. **Output questions:** trace variable values line by line in the margin.
5. Reserve the last 10 minutes to re-check indentation, `:`, `==` vs `=`, `int(input())`, off-by-one in `range`.
6. If stuck on a program, write the algorithm in steps — you still earn partial marks.
